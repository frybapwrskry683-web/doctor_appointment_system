# منشور پروژه (Project Charter)

**نام پروژه:** سامانه نوبت‌دهی مهرطب  



۱. محدوده پروژه (Project Scope)
* **شامل محدوده (In-Scope):**
  * ثبت‌نام و ورود با شماره موبایل
  * جستجوی پزشک و مشاهده تقویم نوبت‌ها
  * رزرو نوبت و پرداخت آنلاین
  * پنل مدیریت پزشک و منشی
* **خارج از محدوده (Out-of-Scope):**
  * اپلیکیشن موبایل مجزا (فقط نسخه وب ریسپانسیو پیاده می‌شود).
  * ویزیت آنلاین و تصویری (در این فاز فقط نوبت‌دهی حضوری است).

۲. تحویل‌دادنی‌های کلیدی (Deliverables)
1. اسناد فاز برنامه‌ریزی (همین مستندات)
2. مدل‌های تحلیل و طراحی (نمودارهای یوزکیس و کلاس)
3. پیاده‌سازی نهایی سامانه
4. گزارش تست و تحویل پروژه

 ۳. نقاط عطف (Milestones)
* **نقطه عطف ۱:** پایان فاز Planning و تایید اسناد (۸ آبان)
* **نقطه عطف ۲:** طراحی پایگاه داده و صفحات (آذر)
* **نقطه عطف ۳:** تحویل نسخه آزمایشی (دی)

#
۴. ریسک‌ها و راهکارها
1. **ریسک:** قطعی درگاه پرداخت یا پنل پیامک.  
   * *راهکار:* استفاده از کدهای جایگزین و تست دقیق در محیط سندباکس.
